## 0. 一句話
新北市南山高級中學的校園網頁遊戲。單一檔案 `index.html`（約 2,940 行，純前端、不需建置），主角是 Q 版「南山豹」，從 7–8 月入學玩到 6 月結業。另有自動展示頁 `showcase.html`。作者：高中部國文科召集人**闕宏宇老師**。**所有介面文字、說明和回覆一律用繁體中文。**

## 3. 每次改完的流程
1. 用本機伺服器開來測（見第 5 節），確認**沒有 JS 錯誤**、對話框正常、手機橫向按鈕不互相蓋住、新的任務點沒卡在建物裡。
2. 改過地圖座標的話，重產 `docs/地圖輪廓/`（做法見 `tools/map-outline.js` 開頭），CSV 只能有一個 BOM。
3. 在 `CLAUDE.md` 的對應段落補上這次的決定（`CLAUDE.md` 是設計紀錄的主檔，請持續更新它；本檔只放交接重點）。
4. 同步到 GitHub：
   ```bash
   bash tools/sync-to-github.sh "這次改了什麼"
   ```
   - 會把 `index.html`、`showcase.html`、`tools/`、`assets/`、交接檔複製進 repo，commit 到 `claude` 分支，再合併到 `main` 推送。
   - 遊戲網址約 1 分鐘後更新：https://s90194yeu-collab.github.io/nanshan-panther-game/
   - 自動展示：https://s90194yeu-collab.github.io/nanshan-panther-game/showcase.html
   - 腳本會自動停下來的情況：GitHub 上的 `index.html` 在上次同步後被別的工具改過、變更裡疑似有金鑰。遇到時**停下來問老師**以哪一份為準，不要硬蓋。

## 4. 程式結構速查（`index.html`）
- 全部程式在一個大 IIFE `(()=>{ ... })();` 裡（檔案最後一個 `})();`）。
- **座標**：資料用「未放大」座標，程式內乘 `K=1.8`；投影 `PX(x)`、`PY(z,y)`，`TILT=.74`、`HS=.46`、`ZS=1.2`（南北向拉長，只在投影與地圖乘，資料不變）。
- **建物**：`building(name,x,z,w,d,h,wall,roof,opts)`（未放大座標）；碰撞 `addBox(x,z,w,d,rot)`（**已放大**座標）；`blocked(x,z)` 判斷是否撞到（已放大座標）。
- **擴充點 `HOOK`**：`HOOK.update`（每幀）、`HOOK.ground`（地面）、`HOOK.actors`（`add(x,z,draw)` 參與前後排序）、`HOOK.overlay`、`HOOK.screen`、`HOOK.map`。新功能盡量掛在這裡，不要改主迴圈。
- **資料表**：`MONTHS`（11 個月）、`TASKS`（任務，`m` 月份、`type`）、`QBANK`／`QLOC`（各科小教室）、`HONORS`＋`HONOR_IMG`（榮譽榜與照片）、`OFFICES`／`LEADERS`／`OFFNPC`（師長）、`HISTORY`（時光碑）、`STALL_SET`（社團攤位）、`GZONES`（地面區塊）、`BINFO`（樓層導覽）、`FIND`（找地點）、`ACTS`（可互動地點）、`KEEP`（不種樹的位置）。
- **國中／高中分流**：`J(國一值, 高一值)`、`only:'j'|'s'`；小六體驗 `VISIT=true`、`G='j'`。快速體驗 `QUICK`＋`QUICK_IDS`。
- **介面**：`dialog({title,text,html,opts,ans,ex,btn,onDone,onClose,por})`、`close()`、`toast()`、`miniGame(cfg,onWin,onQuit)`、`enterMonth(i)`、`complete(t)`、`trigger(t)`。
- **函式宣告可以被覆寫**（例如 `saveGame=()=>{}`），自動展示頁就是這樣關掉存檔的。

## 5. 測試方法與已知的坑（很重要）
- **要用網址開**：在資料夾執行 `python3 -m http.server 8770`，開 `http://127.0.0.1:8770/index.html`。直接雙擊檔案時 `showcase.html` 讀不到遊戲檔。
- **瀏覽器分頁或視窗被藏起來時，`requestAnimationFrame` 會停**，遊戲畫面和走路都不動。測試時視窗要在前景；如果只能在背景測，要自己用 `MessageChannel` 做計時器替身，或直接呼叫 `update(dt)` 推進。
- `tools/screenshot.py` 需要 playwright（目前這台電腦沒裝）。
- 已修過的坑，別再踩：
  - 主迴圈第一幀的時間戳可能早於 `last`，`dt` 變負數會讓水面漣漪半徑變負、整個畫面停住（已在 `loop()` 加 `Math.max(0,…)`）。
  - `shade(hex,f)` 只吃 `#rrggbb`，傳 `rgb()` 字串會得到 NaN 顏色。
  - 建物淡化（玩家走到建物後面時半透明）的計算在 `render` 裡，所以只呼叫 `update` 看不到淡化。
  - 改座標後要確認任務點、時光碑、主任站位、泡泡站位、豹爪幣都沒落在碰撞框裡（`blocked(x*K,z*K)` 為 false），同月任務至少相距 4，新任務點加進 `KEEP`。
  - 用 Python 一次改多處時，**行內註解 `//` 後面不要接程式**，會整段變成註解（自動展示曾因此少走一步）。
  - 時光碑半徑約 1.44（未放大）內會自動跳出對話；路線和瞬移點要避開。

## 6. 自動展示頁 `showcase.html`
- 開始畫面最下面「🎬 自動展示（另開視窗）」會另開它；按「▶ 開始自動展示」後全螢幕自動播，13 個亮點、一輪約 5 分鐘，結束後自動重來，右下「🎮 換我玩！」另開遊戲。網址加 `#auto` 可省略按鈕。
- **不改 `index.html`**：它抓 `index.html` 的文字，在記憶體裡於最後一個 `})();` 前插入 `window.TOUR_API`，再放進 iframe。所以 `index.html` 裡被 API 用到的名稱（`pos`、`joyV`、`keys`、`cam`、`paused`、`TYPING`、`NAV`、`DRILL`、`mgOn`、`STALLS_`、`enterMonth`、`trigger`……）**改名時要一起改 `showcase.html` 的 `API` 字串**，否則展示頁會壞掉。
- 劇本在 `SCENES`；對話停留時間 `readMs()`：老師指定**短的 2 秒、長的最多 6 秒，每月活動說明也是 6 秒**（從打字效果結束開始算）。
- 走路 `walk()` 會繞障礙、快到時放慢、走太久就淡出直接移過去；起點不能放在碰撞框裡（自強大樓一樓北側的電梯樓梯間 `ZQCORE` 曾讓角色卡住抖動）。
