# 給 AI 程式助理（Gemini Antigravity 等）

開工前請依序閱讀：
1. `GEMINI.md`：交接重點、老師的硬性規定、測試方法與已知的坑、待辦。
2. `CLAUDE.md`：完整的設計決定、功能一覽、資料來源（設計紀錄主檔，改完要更新它）。

最重要的幾條：
- 所有回覆與介面文字用**繁體中文**。
- 這個雲端硬碟資料夾是主檔；**不要在這裡 `git init`**，也不要直接改 GitHub 上的檔案。改完執行 `bash tools/sync-to-github.sh "這次改了什麼"`。
- 機密、金鑰、學生資料不得放進資料夾或 repo。
- 不確定的事先問闕宏宇老師，不要猜。
