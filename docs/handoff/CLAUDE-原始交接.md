# 《我的校園生活就是這麼自強不息！～成為南山豹的我，這一年也太充實了吧～》專案交接（給 Claude Code）

（舊名「南山豹的一年」。書名採輕小說風格，一律用正面敘述。）

## 專案是什麼
- 新北市南山高級中學的校園網頁遊戲，靈感來自《臺北狂飆》。
- 單一檔案 `index.html`（約 1600 行），純前端，不需建置，用瀏覽器直接開就能玩。
- 主角是 Q 版、兩腳站立的「南山豹」，從 7–8 月入學一路玩到 6 月結業。
- 每個月有幾個任務（問答、小遊戲、收集、逛攤位），全部完成後蓋章，並自動進入下個月；同時用泡泡框顯示其他年級在做什麼。
- 作者是國文科召集人闕宏宇老師。所有介面文字、說明和回覆一律用**繁體中文**。

## 目標玩家（設計時永遠先想這三種人）
1. **想讀南山的小六生（招生用）**
   - 開場選「🔍 小六體驗」，走國中部（國一）路線。
   - 開場和結局的文字都是寫給小六生看的。
   - 結尾拿到「我的南山體驗卡」。
2. **國一新生**：熟悉校園、處室、行事曆和國中部課程。
3. **高一新生**：熟悉高中部課程（多元選修、自主學習、學習歷程）與校園。

文字要讓小六生看得懂。專有名詞（段考、學校日、直升／外考、學測、學習歷程……）在「📖 南山小辭典」裡有解釋，新增名詞時一併補進 `GLOSS`。

## 已確定的設計決定（請勿任意更動）
1. **畫面風格：非像素的 HD-2D。**
   - 2D Canvas 斜俯視，建物有立體牆面和屋頂。
   - 景深、柔光、光束、光點、暗角、時段色調、雨天都保留。
   - 不用 Three.js、不做 3D、不要像素風。
   - 角色用 SVG 路徑平滑描繪（`charShapes`）。
2. **校園配置。**
   - 依「115 地震避難掩護疏散路線圖」配置，地圖座標全部乘 `K=1.8` 放大，讓人物之間有走路距離。
   - 照片中有「？」的高塔是大中至正樓，右側是行健樓。
3. **年級位置。**
   - 國一在熊祥；國二在自強與崇智。
   - 國三直升班在崇智，國三外考班在曹俊。
   - 高一、高二在大中至正，高三在曹俊。
   - 樓層導覽裡的班級只標年級。
   - 學務處在**崇智樓一樓**（不在熊祥）。
   - 其他年級同學的泡泡站在自己年級的大樓前：`SP` 的 G 曹俊（高三、國三外考）、J 正德、H 熊祥（國一）、I 崇智（國二、國三直升）、E 大中至正（高一、高二）。
   - 兩個校門：廣福門（正門，廣福路，旁邊是有鏤空圓頂的警衛室）、南工門（東側南工路）。
   - 南山藝廊在**曹俊大樓一樓西側**、緊鄰廣福路（不是獨立建築），門口有立牌。
   - 漳二校區＝校園南側（地圖左下）的**風雨光電操場**，平常不可進入；自強大樓西側、行健籃球場東側各有一個小門通往漳二，漳二下方小門通往中和路 217 巷，上放學可從這裡進出（`SIDEDOORS`）。
4. **人物與稱呼。**
   - 董事長、校長、7 位處室主任寫全名，站在校園裡。
   - **組長一律不寫姓名，連姓也不寫**，只顯示「生輔組　組長」「信息組　副組長」。程式裡也已經**完全移除組長姓名**：`OFFICES[].chiefs` 只存單位字串，`CHIEF_NPC` 只存 `{unit, help}`。之後**不可再加回任何組長姓名**。
   - 組長只出現在辦公室對話框裡：靠近主任按 E（手機點 💬）進辦公室才看得到。
5. **制服與南山豹造型。**
   - 主角南山豹依學校吉祥物玩偶設計（2026-11-03 老師提供照片）：黑豹、圓耳灰內耳、琥珀色大眼、白嘴套、橘色鼻子、紅色張嘴。
   - 男生：淺藍襯衫＋深藍領帶＋酒紅背心＋灰短褲；女生：粉紅襯衫與圓領＋酒紅背心＋粉紅裙；背心胸前有綠紅藍三角校徽（`pantherCfg`）。
   - 其他同學（人類角色）仍依服儀準則「男生繡藍字、女生繡紅字」，滾邊藍 `#2f5fb5`、紅 `#d8343f`（`UNI` 常數）。實際配色仍待確認。
6. **課程分流。** 國一和高一課程完全不同，用 `J(國一值, 高一值)` 和 `only:'j'|'s'` 區分。小六體驗時 `G='j'`、`VISIT=true`。
7. **校歌。**
   - 升旗台旁有校歌碑，選單裡也能開校歌，7–8 月另有「新生訓練：學唱校歌」任務。
   - 歌詞和錄音由學校提供，填進 `SONG`。**不要自行補寫或從網路抓歌詞。**
8. **暫不做：班級帳號登入與雲端進度紀錄。** 進度只存在瀏覽器本機（localStorage）。

## 檔案結構（`index.html` 內 `<script>`，依序；搜尋註解標題即可找到）
| 區塊 | 內容 |
|---|---|
| `HD-2D 引擎` | 投影 `PX`／`PY`、常數 `K`（放大倍率）、`HS`（建物高度比例 .46）、`TILT`（俯視壓縮 .74）；`HOOK` 擴充點 |
| `角色：SVG 向量路徑` | `charShapes`、`makeChar`、`drawChar`、`portrait`、`tagCanvas`、`bubbleCanvas` |
| `校園`、`建物資料`、`地面`、`樹` | `building()` 使用**未放大**座標，函式內自動乘 K；碰撞 `addBox`／`hitBox`；`KEEP` 是不種樹的位置 |
| `一學年` | `MONTHS`（11 個月）、`TASKS`；後面接著新增任務、`QBANK`、`QLOC` |
| `辦學成果`、`LEADERS`／`OFFICES`／`CHIEF_NPC` | 榮譽榜、行政團隊（組長無姓名） |
| `其他年級的同學`、`董事長、校長、各處室主任` | `NPCS`、`OFFNPC`、`openOffice`、`chiefCard` |
| `校歌`、`收集物與豹爪幣` | `SONG`、`showAnthem`、`coins`、`flags` |
| `介面`、`小遊戲挑戰`、`大樓樓層導覽` | `dialog({title,text,html,opts,ans,ex,btn,onDone,onClose,por})`、`enterMonth`、`complete`、`trigger`；`MG.*`；`BINFO` |
| `輸入`、`角色`、`小地圖`、`地面材質`、`動態物件`、`後製`、`主迴圈` | 移動、繪製、排序與遮擋淡化 |
| `擴充功能` | 存檔、時段天氣、社團博覽會、各科小教室、大隊接力、找地點、小辭典、集章冊與紀念卡、選單 |

**`HOOK` 擴充點**：新功能盡量掛在這裡，不要去改主迴圈。
- `HOOK.update`：每幀更新（參數 `dt`）。
- `HOOK.ground`：畫地面層。
- `HOOK.actors`：加入要排序的物件，用 `add(x,z,draw)`。
- `HOOK.overlay`：世界座標的最上層。
- `HOOK.screen`：螢幕座標後製。
- `HOOK.map`：小地圖。

## 常見修改
- **各科老師出題。**
  - 在 `QBANK.j`（國中部，也給小六體驗用）或 `QBANK.s`（高中部）加一筆：`{id:'唯一代號', s:'科目', q:'題目', o:['正解','誘答','誘答','誘答'], a:0, ex:'解說'}`。
  - 選項顯示時會自動洗牌，所以正解放第一個（`a:0`）即可。
  - 國中題難度以國小畢業到國一上為準，小六生也要能作答。
- **新增必做任務。**
  - 在 `TASKS` 加：`{m:月份, id, name, x, z, type:'quiz'|'mg'|'talk'|'collect'|'visit'|'final', title, ...}`，座標用未放大值。
  - 加分任務另外加 `opt:true`。
- **新增月份泡泡。** 在 `MONTHS[i].others` 加 `{who, at:'A'~'F', text}`。
- **新增可搜尋地點。** 在 `FIND` 的建立函式裡呼叫 `push(名稱, 位置說明, x, z)`。`BINFO` 的樓層文字（以「・」分隔）會自動加入搜尋。
- **檢查擺放位置。**
  - 新座標要確認不在建物碰撞框裡（`blocked(x*K,z*K)` 回傳 false）。
  - 同月任務之間至少相距 4（未放大值）。
  - 新的任務點也要加進 `KEEP`，避免樹長在上面。

## 測試方式
- 執行 `python3 tools/screenshot.py`：三種身分各跑一次桌機版，另跑一次手機橫向（844×390）。每次截遊戲畫面、選單、處室名冊、找地點四張，並印出 JS 錯誤。
- 每次改完至少確認：
  - 沒有 JS 錯誤。
  - 對話框正常。
  - 手機橫向的按鈕沒有互相蓋住。
  - 新任務點或攤位沒有卡在建物裡。
